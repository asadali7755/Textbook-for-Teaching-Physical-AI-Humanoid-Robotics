# Week 2 - ROS 2 Fundamentals

This week focuses on the Robot Operating System 2 (ROS 2), the middleware framework essential for robotics development.

## Topics to Cover

- Introduction to ROS 2 and its improvements over ROS 1
- Core concepts: nodes, topics, services, actions, and parameters
- Architecture and communication patterns
- Practical examples and implementation
- Integration with Physical AI systems

## Reading Assignment

- ROS 2 fundamentals chapter (index.md)
- Core concepts (concepts.md) 
- Examples and best practices (examples.md)

## Learning Objectives

By the end of this week, you should be able to:

- Explain the architecture and components of ROS 2
- Distinguish between ROS 1 and ROS 2
- Implement basic ROS 2 concepts such as nodes, topics, and services
- Design modular robot software using ROS 2 patterns
- Apply best practices for ROS 2 development

## Practical Exercises

- Create a simple publisher-subscriber pair
- Implement a service for robot state queries
- Work with actions for long-running tasks
- Build a launch file for multiple nodes

## Estimated Hours

- Reading: 4 hours
- Coding exercises: 6 hours
- Review and experimentation: 3 hours
