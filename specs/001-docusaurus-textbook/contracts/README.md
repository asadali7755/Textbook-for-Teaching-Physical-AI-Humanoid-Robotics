# API Contracts: Docusaurus Textbook for Physical AI & Humanoid Robotics

This project is a static documentation website with no backend services, database, or API endpoints as specified in the requirements. Therefore, no API contracts are needed.

## Architecture Decision
- **Type**: Static site generated by Docusaurus
- **Backend**: None (no server-side processing)
- **Database**: None (content stored in Markdown files)
- **API**: None (no dynamic endpoints)

## Technical Rationale
The requirement specifies: "No backend, No database, No API". This means all content is pre-built and served as static files. The site uses client-side rendering only, with all content contained in Markdown files that are processed at build time.

## Navigation and Structure
- Navigation is handled by Docusaurus' built-in sidebar and routing system
- Content is organized in the file structure within the `/docs` directory
- No dynamic data fetching is required as all content is built into the static pages
